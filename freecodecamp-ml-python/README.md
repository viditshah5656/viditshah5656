# freeCodeCamp Machine Learning with Python — five projects

**Vidit Shah** · [Verified certificate](https://www.freecodecamp.org/certification/rockstar5656/machine-learning-with-python-v7)

This folder contains reproducible implementations of the five course challenges.

| Challenge | Approach | Source |
|---|---|---|
| Rock Paper Scissors | Online opponent-model ensemble | [Python](rock-paper-scissors/RPS.py) |
| Cat and Dog Classifier | TensorFlow CNN + image augmentation | [Notebook](cat-and-dog-image-classifier/fcc_cat_dog.ipynb) |
| Book KNN Recommender | Sparse cosine nearest neighbors | [Notebook](book-recommendation-knn/fcc_book_recommendation_knn.ipynb) |
| Health Costs Regression | Keras regression | [Notebook](health-costs-regression/fcc_predict_health_costs_with_regression.ipynb) |
| SMS Text Classification | Keras BiLSTM text classifier | [Notebook](sms-text-classifier/fcc_sms_text_classification.ipynb) |

Open notebooks in Google Colab and run top to bottom. They retrieve datasets from freeCodeCamp's CDN. No dataset, model weights, or fabricated benchmark results are committed. RPS was tested locally against all four bots, while the other notebooks require dataset downloads and model training before accuracy or MAE can be verified. These newly generated sources should not be mistaken for archives of the original certification submissions.
